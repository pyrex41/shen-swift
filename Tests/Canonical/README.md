# Shen 42 canonical tests

`S42/` contains the pristine `S42/Test Programs/` corpus from Mark Tarver's
Shen 42.0 archive (SHA-256 `30abdc7e5a1e27b7a20109c1ed141e4712885e31f24d9710d16415fbbd4dfb23`),
mirrored at `pyrex41/shen-upstream:s42-pristine-20260825`.

The corpus is used by the release smoke test; tests are not compiled into the
Swift module resource bundle.
